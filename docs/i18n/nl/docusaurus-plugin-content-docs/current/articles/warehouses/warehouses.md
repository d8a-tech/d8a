# Warehouses

D8a ondersteunt meerdere warehouse-bestemmingen voor je analyticsdata. Door deze flexibiliteit kun je het data warehouse kiezen dat het beste past bij je infrastructuur, compliance-eisen en analytische behoeften.

Momenteel ondersteunde warehouse-drivers:
- **[BigQuery](/nl/articles/warehouses/bigquery)**: Google's cloud data warehouse voor grootschalige analytics
- **[ClickHouse](/nl/articles/warehouses/clickhouse)**: Snelle, open-source kolomgeoriënteerde database
- **[Object Storage / Files](/nl/articles/warehouses/files)**: Schrijf session-data als CSV-bestanden naar S3/MinIO, GCS of het lokale bestandssysteem — geen database vereist

Zie de afzonderlijke warehouse-driver-gidsen hierboven voor gedetailleerde installatie-instructies.
